Ici on ajoutera si nécessaire les tuto pour tester nos composant individuellement à voir comment on le fait évoluer ce readme.
l'idéal serait d'avoir toujours 5 fichiers par composant pour le system design
exemple
1. Bouton.tsx : Le composant en lui même
2. Bouton.module.css : son apparence avec les tokens
3. Bouton.stories.tsx : les stories permettent de lancer le composant tout seul pour voir à comment il est fait 
4. Bouton.test.tsx : Fichier de test du bouton pour voir si il foncitonne correctement
5. index.ts : La porte d'entré pour plus facilement l'importer partout dans le projet (comme le .h)
